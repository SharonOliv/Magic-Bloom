# Magic Bloom
Draw flowers on the screen with your fingers !<br>
Checkout the link below:<br>
https://magic-bloom.vercel.app/

## Tech
- Plain HTML/CSS/JS, no build step.
- Hand tracking via [MediaPipe Hands](https://github.com/google/mediapipe), loaded from a CDN.
- Everything (camera feed, tracking) runs locally on your device.

## Requirements
- A webcam.
- A modern browser with camera permission granted.
